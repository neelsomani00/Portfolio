P.01

Business landing page

Design & front-end build · Solo project

Goal

Show what a small-business landing page looks like when it's built with real structure — clear hierarchy, a working nav, and sections a client could actually fill with their own content.

Approach

Built the page skeletal-first: layout and information hierarchy locked down before any visual polish, so the structure could be reviewed and reused as the base for the Starter pricing tier.

Outcome

Now used as the reference structure whenever scoping a Starter-tier client site — cuts early planning time down significantly.

E-commerce product page

Design & front-end build · Solo project

Goal

Demonstrate the harder layout problem — filters, a product grid, and card components that stay consistent at any count — without a backend to lean on.

Approach

Structured the grid with reusable card components first, then a sidebar filter layout, keeping everything static but built the way it would need to be if wired to a real product feed later.

Outcome

The card component from this build is what's shown to Grower-tier clients when discussing e-commerce as an add-on.
